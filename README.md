# Speshelty — Tea & Coffee Bar 🐰☕

Українська мережа to-go барів з власним виробництвом, американським стилем та українським ком'юніті.

## 📋 Про проект

**Speshelty** — це сучасний веб-сайт для кав'ярні з наступними функціями:

- ☕ Повне меню напоїв (кава, чай, смузі, десерти)
- 📍 Карта локацій з інтегрованою Leaflet
- 🐰 Інтерактивний маскот (чорний заєць)
- 🌍 Двомовна підтримка (Українська + Англійська)
- 📱 Повністю адаптивний дизайн
- 💾 Інтеграція з Supabase для управління вмістом

## 🚀 Особливості

✨ **Сучасний дизайн** — Gradient, glass-morphism, smooth animations
🎨 **Фірмові напої** — 90% меню це власна розробка
💪 **Wellness лінійка** — Напої з колагеном, протеїном, амінокислотами
🎯 **Spesh Vibe** — Унікальний стиль та характер
